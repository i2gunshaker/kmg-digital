Составь задания курса по главе: @@COUNT@@ штук, все пять типов.

Шаги курса (узлы) с текстом, утверждениями, примерами и задачами книги:
@@NODES@@

Заблуждения доменного пакета (id и текст):
@@MISC@@

Требования:
- Ответ на задание есть в тексте своего шага (step_id). claim_ids — утверждения этого же шага, на которых держится ответ.
- Задания распределены по шагам: не больше двух на шаг, охвачено как можно больше шагов.
- Типы: single (4 варианта, один верный), multiple (4–5 вариантов, верных 2–3), order (4–6 элементов, порядок действий или событий из главы), gap (фраза с одним пропуском {{1}}), calc (расчёт по формуле или числам главы). Не меньше 3 заданий каждого из типов single, multiple, order, gap; calc — столько, сколько позволяют числа главы, но хотя бы одно, если в главе есть расчётная формула или пример.
- Виды (kind): recall — узнавание, understanding — понимание, transfer — перенос на новую ситуацию, data — задание на данных. Узнавания не больше трети.
- Неверные варианты — правдоподобные ошибки новичка. Если вариант построен на заблуждении из списка, укажи его id в misconception, иначе пустая строка. Варианты одной длины и стиля, верный не должен выделяться.
- Опирайся на задачи книги и примеры автора, когда для них не нужен рисунок, которого нет.
- order: options перечисли в перемешанном порядке, answer — id в верном порядке. Порядок должен быть однозначным.
- gap: пропущено одно-два слова, термин или число из текста шага, в той форме, в какой слово стоит во фразе. answer — список из одного элемента.
- calc: все исходные числа есть в prompt. expression — арифметическое выражение из этих чисел (знаки + - * / ** скобки, sqrt, log, log10, exp, pi), которое даёт answer. tolerance — допустимая погрешность в единицах ответа, unit — единица ответа. Для остальных типов expression — пустая строка.
- explanation — одна фраза: почему верно именно это.
- answer_list — ответ списком строк: single — один id варианта; multiple и order — id вариантов; gap — слово; calc — число строкой с точкой.
- Не пиши в задании чисел, которых нет в шаге, кроме исходных чисел задания на перенос в calc.
