Построй граф узлов главы.

Узел — одна законченная идея, которую можно освоить за один шаг курса. Ориентир: @@MIN@@–@@MAX@@ узлов на эту главу. В узле обычно 3–10 единиц и не больше 4500 знаков текста автора. Плотный раздел дели на несколько узлов, а не сжимай. Таблицу с соседним текстом, который её объясняет, держи в одном узле. Формулы вывода держи вместе с абзацами, которые их связывают.

Порядок узлов — для неспециалиста: сначала то, без чего непонятно остальное. Он может отличаться от порядка автора. Предпосылки всегда стоят раньше.

Распредели ВСЕ единицы главы. Каждая единица входит хотя бы в один узел (unit_ids) или стоит в excluded с причиной. Исключать можно только то, в чём нет мысли автора: колонтитул, номер страницы, обрывок подписи на рисунке без смысла, заголовок главы. Причина «непоказуемо» запрещена. Заголовок параграфа отнеси к первому узлу этого параграфа. Обрывки подписей с рисунка и подпись к рисунку отнеси к узлу, который этот рисунок объясняет. Задачи книги и примеры с решением отнеси к узлу, знание которого они проверяют.

Поля узла:
- slug — латиницей, строчными, через подчёркивание, 2–5 слов, по смыслу;
- title — заголовок для новичка, от 3 до 7 слов, без двоеточия;
- title_book — как этот раздел называется у автора (параграф или его часть);
- gist — главная мысль узла одной фразой;
- why_here — почему узел стоит именно здесь, раньше следующих и позже предыдущих;
- primary, secondary — типы трудности; secondary пустая строка, если второго нет;
- threshold — true для пороговой идеи, без которой дальше всё рушится (таких немного);
- decision_on_data — true там, где по признакам принимают решение (признаки, правило, вывод); в главе должен быть хотя бы один такой узел;
- prerequisites — slug узлов, без которых этот непонятен;
- terms_introduced — термины, которые объясняются именно здесь, именительный падеж, русский; каждый термин ровно в одном узле, самом раннем, где он нужен;
- unit_ids — id единиц.
