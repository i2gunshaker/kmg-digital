Опирается на: Уравнение пьезопроводности и его смысл

Суть

Метод ПССС делит пласт на возмущённую и невозмущённую области и двигает границу по балансу упругого запаса. Для галереи при постоянном дебите он даёт границу l(t) = √(2κt). стр. 494–496 · пояснение ИИ

Почему сейчас. Приближённый метод нужен после точных решений. Он проще и показывает, чем точное решение сложнее.

Как это работает

Метод последовательной смены стационарных состояний (ПССС) считает давление по времени медленной величиной. Пласт условно делят на возмущённую и невозмущённую области. В возмущённой области давление стационарно, а её граница движется по балансу упругого запаса. стр. 494, 495 · пояснение ИИ

17. Метод ПССС для галереи при дебите стр. 494–496 · ≈ 3 мин

При постоянном забойном давлении метод ПССС даёт дебит с погрешностью около 5%. Распределение давления в пласте при этом получается грубым приближением.

Q(t) = \frac{k(p_{\text{к}} - p_{\text{г}})}{\mu 2\sqrt{\kappa t}} Bh

19. Радиальный ПССС: давление и формула Дюпюи стр. 497–498

В плоскорадиальном методе ПССС давление внутри возмущённой зоны задано логарифмом отношения R(t) к r. Дебит скважины связан с депрессией формулой, аналогичной формуле Дюпюи. Вне радиуса R(t) давление остаётся начальным.

Условие. Пласт неограниченный, горизонтальный, постоянной толщины h. Скважина имеет радиус rc и постоянный дебит Q.

Условие. До пуска скважины давление во всём пласте одинаково и равно начальному pк.

Условие. Формула распределения давления действительна внутри области R(t). Числовых порогов в этом узле автор не задаёт.

Условие. Формула Дюпюи здесь названа аналогичной, а не точной. Распределение давления принято стационарным по допущению.

Условие. Вне R(t) сохраняется начальное пластовое давление pк.

p(r, t) = p_\text{к} - \frac{Q\mu}{2\pi k h} \ln \frac{R(t)}{r}
Q = \frac{2\pi k h(p_\text{к} - p_c(t))}{\mu \ln(R(t)/r_c)}

20. Граница возмущённой области по балансу стр. 498–499

Баланс упругого запаса даёт радиус возмущённой области R(t), растущий как корень из времени. Формула R(t) = корень из (r_c² + 4κt) получена методом последовательных установившихся состояний (ПССС). Погрешность депрессии по этой формуле зависит от безразмерного времени f_0.

Условие. Погрешность депрессии по методу ПССС: 10,6% при f_0 = 100.

Условие. Погрешность депрессии по методу ПССС: 7,5% при f_0 = 10^3.

Условие. Погрешность депрессии по методу ПССС: 5,7% при f_0 = 10^4.

Условие. Погрешность депрессии по формуле ПССС убывает с ростом времени. Автор даёт три значения погрешности для разных f_0.

Условие. Для случая постоянного забойного давления автор не приводит решения в замкнутом виде, даёт только график.

V(t) = \pi(R^2(t) - r_c^2)h, \quad \Delta p = p_к - \bar{p}
\bar{p} = p_к - \frac{p_к - p_c}{2 \ln(R(t)/r_c)}
\Delta p = p_к - \bar{p} = \frac{p_к - p_c}{2 \ln(R(t)/r_c)} = \frac{Q\mu}{4\pi kh}
4\kappa dt = d(R^2(t) - r_c^2)
R(t) = \sqrt{r_c^2 + 4\kappa t}
p(r, t) = p_к - \frac{Q\mu}{2\pi kh} \ln \frac{\sqrt{r_c^2 + 4\kappa t}}{r}, \quad r_c \leq r \leq \sqrt{r_c^2 + 4\kappa t}
p(r, t) = p_к, \quad r > \sqrt{r_c^2 + 4\kappa t}
\Delta p_c \equiv p_к - p_c(t) = \frac{Q\mu}{2\pi kh} \ln \frac{\sqrt{r_c^2 + 4\kappa t}}{r_c}

21. ПССС при постоянном забойном давлении стр. 499–500

При постоянном забойном давлении метод ПССС даёт дебит с погрешностью около 5%. Распределение давления в пласте при этом получается грубым приближением.

Условие. Погрешность определения дебита по методу ПССС составляет около 5%. Это сравнение с точными расчетами К.А.Царевича и И.Ф.Куранова.

Условие. Точное решение для границы возмущённой области при постоянном забойном давлении в книге не приводится. Закон движения границы берут из графика рис. 24.3.

Дебит скважины определяется по формуле Дюпюи (24.11) при p_c = \text{const}
