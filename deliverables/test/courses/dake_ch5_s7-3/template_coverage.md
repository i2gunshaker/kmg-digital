Шаблон один: реплики сценария идут по кадрам рисунка узла; модель состояния — то, что меняется между кадрами. «Расчёт» — кадры считаются по параметру, «состояния» — схема в нескольких состояниях, «части» — рисунок раскрывается по частям, «статичный» — один кадр.
