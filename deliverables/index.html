Как читать курс

Рядом с каждым утверждением стоит метка. Она показывает, откуда взят факт:

  • стр. N · из книгиСлова автора или пересказ его утверждения. Рядом есть дословная цитата.
  • стр. N · выводВывод из текста автора. На чём он держится, видно в цитате.
  • стр. N · пояснение ИИПояснение, которое модель составила по этим страницам главы.
  • внешнееЗнание из-за пределов главы. Оно не сверялось с книгой.
  • гипотезаВ главе опоры нет. Нужна проверка специалистом.

Куда смотреть. Метка стр. N указывает страницу книги, а под утверждением раскрывается «Цитата автора». В конце каждого шага есть тренажёр с заданиями.

В курсе Латышовой кнопка «Попробовать на реальной скважине Volve →» на первом шаге ведёт к виджету с каротажем скважины 15/9-F-1 B.
