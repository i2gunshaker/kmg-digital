# Глава → курс

Конвейер автоматизированного превращения глав учебников по нефтегазовой геологии, геофизике и разработке (`.md` с постраничной разметкой `<!-- page N -->`) в:
1. Проверенный образовательный граф (`layer.json`) со 100% биективным покрытием исходной главы (`coverage.json`) и маршрутизацией форматов (`routing.json`).
2. Автономный офлайн-курс (`index.html`, работает напрямую по `file://` без сервера и сети), содержащий детерминированные векторные иллюстрации классов A и B, интерактивный разбор задач с подтягиванием зависимостей, тренажёры 5 типов и виджет на реальных открытых данных Equinor Volve `15/9-F-1 B`.
3. Учебные видеоролики из проверенного слоя (9:16 шортс `40–75 с` и 16:9 разбор `1,5–3 мин`) с паспортами (`passport.json`): HTML/SVG-сцены курса → Playwright → ffmpeg, проверка звука (`-16 LUFS`, `faster-whisper`/`mlx-whisper` `WER <= 10%`, сдвиг `<= 0,5 с`).
4. Внешний модуль проверки качества на типовые физические, числовые, логические и визуальные ошибки («закладки»).

## Быстрый старт

### 1. Ветка и зависимости

Рабочая ветка — `avervill`:

```bash
git checkout avervill
git pull origin avervill
```

Python 3.12+ (рекомендуется локальное `.venv`) и Node.js 20+:

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt

cd video && npm install && cd ..
```

Системные утилиты (для видео и аудио-этапов): `ffmpeg`.

### 2. Входные материалы и секреты (вне git)

Материалы кейса и книги организаторов хранятся вне репозитория (по умолчанию в `~/Downloads/хакатон-2`, переопределяется переменной `KURS_INPUT_DIR`).

Для LLM-этапов и опционального TTS создайте файл `.env` в корне репозитория (не индексируется git):

```bash
read -s -p "API Key: " KEY && printf '\nANTHROPIC_API_KEY=%s\n' "$KEY" >> .env && unset KEY
```

Поддерживаемые переменные `.env`:
- `KURS_INPUT_DIR` — путь к папке с материалами организаторов (если отличается от `~/Downloads/хакатон-2`).
- `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` — ключи облачных провайдеров (также поддерживаются `KURS_LLM_BACKEND`, `KURS_LLM_MODEL`, `OPENAI_BASE_URL`).
- `ELEVENLABS_API_KEY` — озвучка через ElevenLabs (выбирается сама, если ключ есть); `ELEVENLABS_VOICE_ID` — другой голос; `KURS_TTS=edge|silero|elevenlabs` — выбрать синтезатор явно.

## Доступные команды CLI (`python -m kurs`)

```bash
# Нарезать настроенные главы (или произвольный .md) на устойчивые единицы
.venv/bin/python -m kurs units all
.venv/bin/python -m kurs units path/to/chapter.md

# Проверить ключ и доступность моделей (бесплатно)
.venv/bin/python -m kurs llm

# Прогноз цены главы и остаток общего предела (бесплатно); наборы моделей — cheap, mid, max
.venv/bin/python -m kurs cost path/to/chapter.md
.venv/bin/python -m kurs cost all --profile mid

# Построить слой, покрытие, маршрутизацию и задания
# Без --max-usd платных вызовов нет: работают кэш build/.cache/llm, починка кодом, маршруты и задания по правилам
# Готовые layer/routing/tasks второй раз не делаются (переделать — --redo)
# Обрыв API не теряет работу: слой собирается без пропущенных запросов (missed_calls), повторный запуск доделывает их
.venv/bin/python -m kurs gen latyshova_gl5_par17-20
.venv/bin/python -m kurs gen path/to/chapter.md --max-usd 0.5

# Проверить готовый слой и 100% покрытие по схемам, цитатам, числам и терминам
.venv/bin/python -m kurs check latyshova_gl5_par17-20 path/to/layer.json path/to/coverage.json

# Собрать автономный офлайн-курс (file://) и прогнать приёмку
.venv/bin/python -m kurs course latyshova_gl5_par17-20 --layer path/to/layer.json

# Сгенерировать и проверить спецификации сцен и паспорта двух обучающих роликов (в build/specs/)
.venv/bin/python -m kurs specs
```

Запуск, пересборка, проверка и ролики (подробно — [PLAYBOOK.md](PLAYBOOK.md)):

```bash
# Полный прогон незнакомой главы (RU/EN) одной командой: единицы → слой → покрытие → маршруты → задания → рисунки → проверка → курс → метрики
.venv/bin/python -m kurs run path/to/chapter.md --max-usd 0.5 [--video]

# После ручной правки факта в layer.json: что устарело, и пересборка без вызовов модели
.venv/bin/python -m kurs plan latyshova_gl5_par17-20
.venv/bin/python -m kurs rebuild latyshova_gl5_par17-20 [<node_id>] [--video]

# Проверка в строгом режиме: смысловые замечания (отрицание, направление, условие, допущение, обобщение) — ошибки
.venv/bin/python -m kurs check latyshova_gl5_par17-20 --strict

# Фаззинг валидатора: сколько внесённых ошибок поймано и сколько ложных тревог на чистом слое
.venv/bin/python -m kurs fuzz latyshova_gl5_par17-20

# Модуль «Закладки»: слепая проверка чужого пакета (key.json не открывается); вход и выход — по схемам организаторов
.venv/bin/python -m kurs.review package.json -o build/review/ctrl_blind_v1.json --max-usd 0.3

# Смежный домен: тот же конвейер с пакетом бурения
.venv/bin/python -m kurs run path/to/chapter.md --domain drilling --max-usd 0.5

# Ролики из проверенного слоя: шортс 9:16 и разбор 16:9 (--dry — только сценарий и паспорт)
.venv/bin/python -m kurs video latyshova_gl5_par17-20 [--node <id>] [--format shorts|long] [--dry]

# Метрики в build/metrics.csv и таблица для MANIFEST.md
.venv/bin/python -m kurs metrics --manifest
```

## Как устроена достоверность

- **Слой — единственный источник истины.** Курс, задания, рисунки и ролики выводятся из `layer.json`. После сборки в `build/<глава>/manifest.json` пишутся хэши узлов и утверждений и что на них опирается; `kurs plan` показывает diff, `kurs rebuild` пересобирает только устаревшее ([kurs/pipeline.py](kurs/pipeline.py)).
- **Проверки без модели** ([kurs/verify.py](kurs/verify.py), [kurs/claimcheck.py](kurs/claimcheck.py)): цитата дословно на своей странице; числа со знаком, единицей и неравенством; отрицание, направление изменения, условие, оговорка автора, обобщение — по той части цитаты, которая ближе всего к утверждению. Покрытие: каждая единица отдана узлу или исключена с причиной из закрытого списка; единица, отданная узлу, на которую ничто не опирается, — `mapped_but_untaught`.
- **Фаззинг** ([kurs/fuzz.py](kurs/fuzz.py)): те же ошибки вносятся в верные утверждения нарочно; отчёт «внесли N, поймано M, вот что пропущено» и фон ложных тревог.
- **Происхождение** ([kurs/provenance.py](kurs/provenance.py)): у каждого абзаца курса бейдж «из книги / вывод / пояснение ИИ / внешнее / гипотеза» и страница.
- **Задания**: неверный вариант — искажение утверждения того же шага (другое число, обратное направление, потерянное условие), и проверка подтверждает, что автор этого не говорит; задания на перенос — по правилу «решения на данных».
- **Ролики** ([kurs/video.py](kurs/video.py), [kurs/tts.py](kurs/tts.py)): озвучка — проверенные утверждения, связки без чисел; кадры — рисунки и формулы курса (Playwright); числа словами с падежами, словари произношения и ударений; −16 LUFS (loudnorm в два прохода), WER и сдвиг по распознаванию; паспорт по схеме.

## Расход на LLM

- Платные вызовы выключены, пока не указан `--max-usd` (или `KURS_LLM_BUDGET`). Предел один на все главы запуска.
- Общий предел за всё время — `llm.total_usd` в `config.yaml`; он считается по `build/llm_usage.jsonl` и не даёт превысить бюджет повторными запусками.
- Место под цену вызова бронируется до вызова, второй платный запуск рядом не стартует, модель без цены в `llm.prices` не вызывается.
- Карточки сначала чинит код ([kurs/repair.py](kurs/repair.py)): цитаты, числа, термины, длина фраз. Модель возвращает только короткие правки оставшихся мест, а не карточку целиком.
- Судья (`llm.judge`) сверяет карточки с источником по смыслу; правки вносит код, журнал — в `gen_report.json`. Если рядом есть PDF с текстовым слоем и установлен `pdftotext`, индексы формул сверяются по нему.
- Без модели маршруты и задания строятся по правилам ([kurs/rules.py](kurs/rules.py)); в `gen_report.json` это отмечено полями `routing_by` и `tasks_by`.

## Структура репозитория

```text
├── config.yaml                  # Конфигурация путей, LLM-бэкендов и глав корпуса
├── kurs/
│   ├── config.py                # Загрузка config.yaml и .env, поддержка произвольных .md (RU/EN)
│   ├── units.py                 # Нарезка глав на единицы, фильтрация модельных описаний рисунков, детектор OCR
│   ├── verify.py                # Проверка схем, дословных цитат, чисел (знак/единица/условие), терминов и покрытия
│   ├── llm.py, cost.py          # Переходник к LLM: кэш, учёт расхода, пределы; прогноз цены главы
│   ├── layer_gen.py, judge.py   # Генерация слоя и покрытия, исправление по проверке, смысловая сверка с главой
│   ├── quotes.py, repair.py     # Привязка цитат к тексту и починка карточек кодом, без модели
│   ├── pdfref.py                # Текстовый слой PDF как справка для чтения индексов
│   ├── tasks_gen.py, rules.py   # Маршрутизация и задания: моделью или по правилам; prompts/ — тексты промптов
│   ├── datasets.py              # Загрузка и проверка SHA-256 открытого среза Equinor Volve 15/9-F-1 B
│   ├── illustrations.py         # Детерминированные SVG-иллюстрации классов A и B по styleguide.json
│   ├── course.py                # Сборка автономного офлайн-курса (file://, inline JSON, Volve-виджет, задания)
│   ├── video_spec.py            # Спецификации двух обучающих роликов (ручные, ранние) и бриф в build/specs/
│   ├── video.py, tts.py         # Ролики из слоя: сценарий, кадры, озвучка, громкость, распознавание, паспорт
│   ├── claimcheck.py            # Смысловые проверки утверждения против цитаты и мутации для фаззинга и заданий
│   ├── fuzz.py, review.py       # Фаззинг валидатора; модуль «Закладки» (код + модель по тексту + зрение по кадрам + второй проход)
│   ├── pipeline.py, metrics.py  # run / plan / rebuild по хэшам; metrics.csv и таблица для MANIFEST.md
│   ├── provenance.py            # Происхождение абзацев курса: из книги / вывод / пояснение ИИ / внешнее / гипотеза
│   ├── templates/ & static/     # Шаблон course.html.j2, стили и клиентский JS офлайн-курса
├── domain/geology/              # Доменный пакет: стайлгайд, заблуждения, чек-лист физики, глоссарий, ударения, Volve
├── domain/drilling/             # Доменный пакет бурения той же структуры (ЭЦД, ГНВП, окно бурения, КНБК, MWD/LWD)
├── video/                       # Playwright: проверка курса (qa_course.mjs) и съёмка кадров роликов (render_scenes.mjs)
├── tests/                       # Тесты парсинга, верификации, курса, Volve и спецификаций видео
└── build/                       # Локальные артефакты сборки (в .gitignore)
```
