# Правила произношения обозначений и аббревиатур (для озвучки)

При первом упоминании аббревиатура раскрывается словами полностью, далее произносится по таблице. Буквы через пробел/дефис синтезатор читает раздельно.

| Пишется | Читается | Расшифровка |
|---|---|---|
| ГИС | гэ-и-э́с | геофизические исследования скважин |
| ПС | пэ-э́с | потенциалы самопроизвольной поляризации |
| СП | эс-пэ́ | метод собственной поляризации |
| ГК | гэ-ка́ | гамма-каротаж |
| ГМ | гэ-э́м | гамма-метод |
| НГК | эн-гэ-ка́ | нейтронный гамма-каротаж |
| ННК | эн-эн-ка́ | нейтрон-нейтронный каротаж |
| НМ | эн-э́м | нейтронные методы |
| ГГК-П | гэ-гэ-ка́-пэ́ | гамма-гамма-каротаж плотностной |
| АК | а-ка́ | акустический каротаж |
| КС | ка-э́с | кажущееся сопротивление |
| БК | бэ-ка́ | боковой каротаж |
| ИК | и-ка́ | индукционный каротаж |
| БКЗ | бэ-ка-зэ́ | боковое каротажное зондирование |
| МКЗ | эм-ка-зэ́ | микрокаротажное зондирование |
| ЯМР | я-эм-э́р | ядерно-магнитный резонанс |
| ВНК | вэ-эн-ка́ | водонефтяной контакт |
| ГНК | гэ-эн-ка́ | газонефтяной контакт |
| ГВК | гэ-вэ-ка́ | газоводяной контакт |
| ГЖК | гэ-жэ-ка́ | газожидкостный контакт |
| ГДИС | гэ-дэ-и-э́с | гидродинамические исследования скважин |
| КВД | ка-вэ-дэ́ | кривая восстановления давления |
| ПССС | пэ-эс-эс-э́с | метод последовательной смены стационарных состояний |
| Kп, kп | ка-пэ́ | коэффициент пористости |
| Kпр | ка-пэ-э́р | коэффициент проницаемости |
| Kн, Kв | ка-э́н, ка-вэ́ | коэффициенты нефте- и водонасыщенности |
| ρп, ρв | ро-пэ́, ро-вэ́ | удельное сопротивление пласта, пластовой воды |
| Rw, Rt | эр-вэ́, эр-тэ́ | сопротивление пластовой воды, истинное сопротивление пласта |
| GR | джи-а́р | гамма-каротаж (западная шкала, единицы API) |
| SW | эс-да́бл-ю или эс-вэ́ | водонасыщенность |
| PHIF | фи-эф | итоговая пористость |
| β* | бе́та со звёздочкой | коэффициент упругоёмкости пласта |
| κ | ка́ппа | коэффициент пьезопроводности |
| Ei | и-а́й | интегральная показательная функция |
| Ом·м | ом-ме́тр | единица удельного электрического сопротивления |
| мД | миллида́рси | единица проницаемости |
| МПа | мегапаска́ль | единица давления |
| м²/с | квадра́тный метр в секунду | единица пьезопроводности |
