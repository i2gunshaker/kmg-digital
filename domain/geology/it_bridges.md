# ИТ-аналогии домена с обязательными границами применимости

| Идея геологии / физики | ИТ-аналогия | Где аналогия перестаёт работать (`breaks_where`) |
|---|---|---|
| Комплексирование ГИС в смешанном разрезе (одному значению $R_t$ соответствуют разные породы) | Сдвиг домена (domain shift) и многопризнаковая классификация (sensor fusion) вместо одного порога | Сдвиг здесь не статистический шум, а смена физики породы, минерализации воды или типа раствора, известная заранее по скважинным условиям |
| Критические пороги $k_\text{п}^*$, $P_\text{н}^*$, $\alpha_\text{СП}^*$ | Калиброванный бинарный классификатор с двумя порогами: «нефть / серая зона / вода» | Между $P_\text{н}^*$ и $P_\text{н}^{**}$ лежит физическая двухфазная область, где скважина даёт и нефть, и воду; пороги не переносятся на другой тип породы |
| Уравнение пьезопроводности $\partial p / \partial t = \kappa \Delta p$ | Диффузионное сглаживание (теплопроводность / графовая диффузия) по сетке | Возмущение расходится не линейно со скоростью сигнала, а диффузионно как $\sqrt{\kappa t}$ с бесконечным экспоненциальным хвостом |
| Метод ПССС Чарного ($R(t) = \sqrt{r_c^2 + 4\kappa t}$) | Аппроксимация ядра диффузии движущимся окном активных узлов с балансом массы на границе | На подвижной границе $R(t)$ градиент давления терпит скачок, поэтому профиль $p(r)$ грубый (ошибка по депрессии до 11–25%), хотя связь дебит–депрессия точна |
| Обратная задача КВД / ГДИС (оценка $k$ и границ по кривой давления) | Некорректно поставленная обратная задача восстановления параметров среды по временному ряду на одном датчике | Разные сочетания неоднородностей и границ дают схожие кривые; модель без проверки геометрии и априорных ограничений неоднозначна |
| Вторичная пористость рифов (первичная зарастает цементом, каверны создаются карстом) | Мутация схемы данных после миграции: исходный индекс больше не отражает фактическое распределение ключей | События диагенеза и карста необратимы и пространственно неоднородны: соседние интервалы карбоната могут отличаться по дебиту на порядки |
