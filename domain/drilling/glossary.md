# Глоссарий домена (бурение скважин, давление в стволе, буровой раствор)

## Термины RU / EN

| Термин (RU) | Определение для новичка | Западный аналог (EN) | Обозначение (RU / EN) |
|---|---|---|---|
| Буровой раствор | Жидкость, которую насосы прокачивают через бурильную колонну и долото и которая по затрубью возвращается на поверхность: создаёт давление на стенки и забой, выносит шлам, охлаждает долото | Drilling fluid / Mud | — / MW (плотность) |
| Плотность бурового раствора | Масса единицы объёма раствора; задаёт гидростатическое давление столба | Mud weight / Mud density | $\rho_\text{р}$ / MW, ppg, SG |
| Гидростатическое давление | Давление неподвижного столба раствора на глубине: $P_\text{г} = \rho g H$, где $H$ — глубина по вертикали | Hydrostatic pressure | $P_\text{г}$ / $P_\text{hyd}$ |
| Пластовое (поровое) давление | Давление флюида в порах пласта; ниже него раствор не удерживает приток | Pore / Formation pressure | $P_\text{пл}$ / $P_\text{p}$ |
| Давление гидроразрыва | Давление, при котором порода раскрывает трещину и начинает поглощать раствор | Fracture pressure / Fracture gradient | $P_\text{гр}$ / $P_\text{frac}$, FG |
| Окно бурения | Диапазон давлений в стволе между пластовым давлением (и давлением обрушения стенок) снизу и давлением гидроразрыва сверху | Drilling window / Mud weight window | — |
| Эквивалентная циркуляционная плотность (ЭЦД) | Плотность, которой соответствовало бы забойное давление при циркуляции: статическая плотность плюс потери давления на трение в затрубье, пересчитанные на глубину по вертикали | Equivalent circulating density | ЭЦД / ECD |
| Затрубье (затрубное пространство) | Кольцевой зазор между бурильной колонной и стенкой скважины или обсадной колонной; по нему раствор поднимается вверх | Annulus | — |
| Газонефтеводопроявление (ГНВП) | Неконтролируемый приток пластового флюида в скважину, когда давление в стволе ниже пластового | Kick / Well control incident | ГНВП / kick |
| Открытый фонтан (выброс) | ГНВП, которое не удалось закрыть: флюид выходит на поверхность | Blowout | — |
| Противовыбросовое оборудование (ПВО) | Превенторы на устье, которые закрывают скважину при ГНВП | Blowout preventer | ПВО / BOP |
| Глушение скважины | Замена раствора в стволе на раствор такой плотности, чтобы забойное давление стало выше пластового, с выводом поступившего флюида через штуцер | Well kill | — |
| Поглощение бурового раствора | Уход раствора из ствола в пласт: в трещины, каверны или через трещину гидроразрыва | Lost circulation / Losses | — |
| Поршневание (подъём) | Снижение давления на забое при быстром подъёме колонны: раствор не успевает заполнить освобождаемый объём | Swabbing | — / swab |
| Поршневой эффект при спуске | Рост давления на забое при быстром спуске колонны: раствор вытесняется вверх с трением | Surging | — / surge |
| Долото | Породоразрушающий инструмент на конце колонны | Bit (PDC, roller cone) | — |
| Компоновка низа бурильной колонны (КНБК) | Нижняя часть колонны: долото, двигатель или роторная управляемая система, утяжелённые трубы, стабилизаторы, телеметрия | Bottom hole assembly | КНБК / BHA |
| Утяжелённые бурильные трубы (УБТ) | Толстостенные трубы над долотом, создающие нагрузку на долото | Drill collars | УБТ / DC |
| Нагрузка на долото | Часть веса колонны, передаваемая на долото | Weight on bit | — / WOB |
| Механическая скорость проходки | Скорость углубления забоя, м/ч | Rate of penetration | $V_\text{мех}$ / ROP |
| Частота вращения и крутящий момент | Обороты колонны (об/мин) и момент на роторе или верхнем приводе | RPM, Torque | — |
| Шлам | Обломки разрушенной породы, которые раствор выносит по затрубью | Cuttings | — |
| Каверна | Участок ствола с диаметром больше номинального из-за размыва или обрушения стенок | Washout / Cave-in | — |
| Кавернометрия | Измерение диаметра ствола по глубине | Caliper log | — / CAL |
| Фильтрационная корка | Слой твёрдой фазы раствора на стенке напротив проницаемого пласта; образуется, когда фильтрат уходит в пласт | Filter cake / Mud cake | — |
| Дифференциальный прихват | Колонну прижимает к стенке разность давлений «ствол — пласт» через фильтрационную корку; колонна перестаёт двигаться | Differential sticking | — |
| Обсадная колонна | Стальные трубы, спущенные в скважину и зацементированные, чтобы закрепить ствол и разобщить пласты | Casing | — |
| Башмак обсадной колонны | Нижний конец колонны; под ним обычно самое слабое место открытого ствола | Casing shoe | — |
| Цементирование | Закачка цементного раствора в затрубье за обсадной колонной | Cementing | — |
| Испытание на приёмистость (утечку) пласта | Опрессовка открытого ствола под башмаком до начала поглощения (LOT) или до заданного давления без поглощения (FIT) | Leak-off test / Formation integrity test | — / LOT, FIT |
| Глубина по вертикали | Расстояние от устья до точки по вертикали; по ней считают гидростатику | True vertical depth | — / TVD |
| Глубина по стволу | Длина ствола от устья; по ней считают трение и объём | Measured depth | — / MD |
| Давление в бурильных трубах и затрубье при закрытой скважине | Устьевые давления после закрытия ПВО; по ним считают пластовое давление и плотность раствора глушения | Shut-in drillpipe / casing pressure | — / SIDPP, SICP |
| Геолого-технологические исследования (ГТИ) | Непрерывный контроль параметров бурения и раствора на поверхности: объём в ёмкостях, расход, давление, газ, нагрузка | Mud logging / Surface data logging | ГТИ / — |
| Телеметрия во время бурения | Скважинные датчики в КНБК, передающие данные на поверхность (давление, наклон, азимут, каротаж) | MWD / LWD | — |

## Связь величин (без чисел конкретных книг)

| Величина | Как связана | Где ошибаются |
|---|---|---|
| Гидростатика | $P_\text{г} = \rho g H$, $H$ — глубина по вертикали (TVD) | Считать по длине ствола (MD) в наклонной скважине |
| ЭЦД | ЭЦД $= \rho + \Delta P_\text{затр} / (g H)$ | Считать, что при циркуляции забойное давление равно статическому |
| Условие без ГНВП | Давление на забое ≥ пластового на всех режимах (циркуляция, остановка, подъём) | Забыть о поршневании при подъёме и об остановке насосов |
| Условие без поглощения | ЭЦД и давление при спуске ≤ давления гидроразрыва под башмаком | Считать, что тяжелее раствор — всегда безопаснее |
