# Правила произношения обозначений и аббревиатур (для озвучки)

При первом упоминании аббревиатура раскрывается словами полностью, далее произносится по таблице. Буквы через пробел/дефис синтезатор читает раздельно.

| Пишется | Читается | Расшифровка |
|---|---|---|
| ЭЦД | э-цэ-дэ́ | эквивалентная циркуляционная плотность |
| ГНВП | гэ-эн-вэ-пэ́ | газонефтеводопроявление |
| ПВО | пэ-вэ-о́ | противовыбросовое оборудование |
| КНБК | ка-эн-бэ-ка́ | компоновка низа бурильной колонны |
| УБТ | у-бэ-тэ́ | утяжелённые бурильные трубы |
| ВЗД | вэ-зэ-дэ́ | винтовой забойный двигатель |
| РУС | эр-у-э́с | роторная управляемая система |
| СПО | эс-пэ-о́ | спуско-подъёмные операции |
| ГТИ | гэ-тэ-и́ | геолого-технологические исследования |
| АВПД | а-вэ-пэ-дэ́ | аномально высокое пластовое давление |
| ECD | и-си-ди́ | equivalent circulating density |
| BHA | би-эйч-э́й | bottom hole assembly |
| BOP | би-оу-пи́ | blowout preventer |
| MWD | эм-дабл-ю-ди́ | measurement while drilling |
| LWD | эл-дабл-ю-ди́ | logging while drilling |
| ROP | эр-оу-пи́ | rate of penetration, механическая скорость |
| WOB | дабл-ю-оу-би́ | weight on bit, нагрузка на долото |
| RPM | эр-пи-э́м | обороты в минуту |
| TVD | ти-ви-ди́ | глубина по вертикали |
| MD | эм-ди́ | глубина по стволу |
| LOT | эл-оу-ти́ | испытание на приёмистость пласта |
| FIT | эф-ай-ти́ | испытание на герметичность пласта |
| SIDPP | эс-ай-ди-пи-пи́ | давление в бурильных трубах при закрытой скважине |
| SICP | эс-ай-си-пи́ | давление в затрубье при закрытой скважине |
| WITSML | ви́тсмл | стандарт обмена данными бурения |
| PDC | пи-ди-си́ | долото с поликристаллическими алмазными резцами |
| г/см³ | грамм на кубический сантиметр | единица плотности раствора |
| МПа | мегапаска́ль | единица давления |
| м/ч | метров в час | единица механической скорости |
| кН | килонью́тон | единица нагрузки на долото |
| кН·м | килонью́тон-ме́тр | единица крутящего момента |
